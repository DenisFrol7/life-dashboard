# Life Dashboard Frontend

Клиентская часть Life Dashboard на React, TypeScript, React Router и Vite.

## Запуск

Backend должен быть доступен на `http://localhost:8080`. В режиме разработки Vite
проксирует запросы `/api` на backend.

```powershell
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173`.

Для отдельного адреса API скопируйте `.env.example` в `.env` и задайте
`VITE_API_URL`. Пустое значение использует текущий origin и локальный proxy.

## Организация стилей

- `src/index.css` — базовые стили, глобальные CSS-переменные и палитры тем.
- `src/App.css` — общий каркас приложения, адаптивная компоновка и расположение общих элементов.
- CSS-файл рядом с компонентом — только оформление этого компонента и его состояний; файл импортируется самим компонентом.

Обычный CSS остаётся глобальным независимо от расположения файла. Для новых
компонентов используйте собственный префикс классов, например `mobile-menu-`.
Общие отступы страницы и правила для `html`, боковой панели, верхней панели и
уведомлений размещайте в `App.css`, а переменные, используемые несколькими
частями приложения, — в `index.css`.

Существующие стили страниц в `App.css` переносите в отдельные файлы постепенно,
при работе над соответствующей страницей.
